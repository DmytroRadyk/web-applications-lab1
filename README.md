# Лабораторна робота №1 — Ruby Koans

Виконані вправи з Ruby: значення, рядки, символи, масиви, хеші, методи, винятки, блоки, класи, модулі, успадкування, метапрограмування та pattern matching.

## Запуск

Потрібен Ruby 3.3 та Bundler.

~~~sh
bundle install
bundle exec rake
bundle exec rake verify
~~~

`rake` запускає оригінальний навчальний runner. `rake verify` додатково перевіряє кожен тест оригінальними assertions і повертає ненульовий exit code при помилці — для CI. Перевірено: **299 koans, усі успішні** на Ruby 3.3.13.

## Реалізовані проєкти

- `triangle.rb`: класифікація трикутників і перевірка нерівності трикутника.
- `lib/score.rb`: підрахунок очок Greed, без зміни вхідного масиву.
- `lib/dice_set.rb`: кидки кубиків з можливістю передати генератор випадкових чисел.
- `about_proxy_object_project.rb`: делегування методів, аргументів і блоків та журнал викликів.
- `greed.rb`: додаткове завдання — повна гра: поріг входження 300, втрата очок ходу при невдалому кидку, повторний кидок п’яти кубиків і фінальне коло від 3000 очок.

~~~sh
ruby greed.rb "Гравець 1" "Гравець 2"
~~~

Для повторного кидка введіть `y`, для завершення ходу — Enter. Правила: [GREED_RULES.txt](GREED_RULES.txt).

Порядок вправ визначений у `path_to_enlightenment.rb`. Pattern matching включено для Ruby 3. Старі вправи JRuby/Java та гілки Ruby 1.8 збережені зі стартового набору; вони не належать до перевірки MRI Ruby 3.3. Підтримку assertions у `neo.rb` не змінено.
